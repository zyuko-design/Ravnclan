CONTENU
- index.html : site responsive en une page
- assets/ravn-logo.png : logo RAVN fourni

POUR LE PERSONNALISER
1. Ouvre index.html dans un navigateur pour prévisualiser le site.
2. Remplace https://discord.gg/REMPLACE-MOI par ton vrai lien d'invitation Discord.
3. Remplace PLAYER 01, PLAYER 02, etc. par les pseudos du roster.
4. Pour publier le site, dépose le dossier sur un hébergeur de site statique (par exemple Netlify ou Vercel).

IMPORTANT
Le site est une vitrine statique. Les candidatures privées seront gérées par les tickets Discord : ajoute un bot de tickets et configure ses permissions dans ton serveur.
