RAVN CLAN — SITE AVEC PANNEAU ADMINISTRATEUR

Ouvre index.html dans ton navigateur.
Clique sur « ADMIN PANEL » en bas à droite pour modifier le site directement :
- nom, slogan, textes et titres
- couleurs
- logo (image depuis ton appareil)
- joueurs et rôles du roster
- cartes / valeurs
- lien Discord et texte du bouton

Clique sur ENREGISTRER LES MODIFICATIONS.
Les changements sont stockés dans le navigateur utilisé (localStorage).

IMPORTANT :
Cette version est un site statique avec administration locale. Les changements ne sont pas automatiquement envoyés à tous les visiteurs. Pour un site public où les modifications faites depuis le panneau sont publiées pour tout le monde, il faut connecter une base de données et une authentification à un hébergement web. Le bouton EXPORTER LA CONFIGURATION permet de sauvegarder les réglages en JSON.
Remplace le lien Discord provisoire par ton invitation réelle.
